# Clash 對撞系統 v2 使用者指南

> **這次更新的重點：可以多人一起打同一個反派，而且反派會有你看得到的血條。**

---

## 一、這次更新了什麼

以前 `/clash` 一次只能**單挑**，一次對撞就兩個人。

現在：

- **多人打一個反派**：同一段劇情裡好幾個玩家一起圍攻同一隻魔物／反派，系統會把大家的傷害**合併成一次結算**。
- **反派血條會自動出現**：偵測到魔物／反派時，系統依它在劇情裡的表現自動建立數據（全自動，沒人需要填表）。
- **血條對所有人可見**：直接貼在討論串上，是訊息文字進度條。
- **血條歸零 = 打敗或擊退。**

單挑完全沒變，照舊能用。

---

## 二、玩家怎麼玩（三步，零負擔）

1. **照平常 RP，用你自己的角色描述行動**（用了什麼招式、想幹嘛）。
2. 討論串裡任何一位中之人執行 **`/clash`**。
3. 系統把血條 + 一行理由貼在討論串上。

你**不需要**輸入角色名、招式、數值、目標，也不需要輪流操作或協調誰先誰後。

---

## 三、你會看到什麼

```
██████░░░░ 12B/24B 魔王 破防 -40 ticks
```

- `██████░░░░` — 血條本體。
- `12B/24B` — 目前血量／最大血量。`B` 只是顯示單位。
- `魔王 破防 -40 ticks` — **一行理由**：這回合為什麼扣血、扣了多少。

理由行也會出現這些情況：

- `全員僵持 chip -2 ticks` — 大家這回合都沒打穿，只磨掉一點。
- `未造成有效傷害` — 這回合完全沒進展。
- `已達擊退線，可宣告擊退` — 反派被壓到底了。
- `❌ 魔王 已被擊敗（HP 歸零）` — 打敗。
- `💨 魔王 被擊退（守住 20% 擊退線）` — 擊退。

---

## 四、玩家一定要知道的規則

| 規則 | 說明 |
|---|---|
| **你不能宣告結果** | 只能描述「你角色做了什麼」。打出什麼結果由系統判定，玩家不能單方面說「我一劍砍死魔王」。 |
| **留手是你自己的選擇** | 留手**只影響你自己的**判定（把碾壓降級），不會影響別人，系統也**不會**替任何人打折威力。想留手就用描述體現。 |
| **不能替別人決定動作** | 你只能寫自己角色的行動。別人要出什麼招，由他自己寫。 |
| **傷害會合併、有上限** | 多人一起打是**一次**結算、**一筆**扣血。所以五個人圍毆不會變成秒殺。 |
| **僵持磨不死人** | 全員打不穿時只會磨掉一點點，而且最多把反派壓到「擊退線」，**永遠不會靠僵持把血條歸零**。 |
| **歸零 = 打敗；壓到底 + 有人宣告 = 擊退** | **擊退不會自動發生**，要在劇情裡由中之人宣告。系統不會自己幫你結束戰鬥。 |
| **被擊退的反派會記帳** | 之後再登場是**從當時的血量續戰**，不會自動回滿。要回復得靠劇情中的「休整恢復」事件（管理員記錄）。 |

---

## 五、反派分級（決定血條多長、每回合最多扣多少）

| 分級 | 血條長度 | 每回合上限 | 擊退線 |
|---|---|---|---|
| 雜兵 | 50 | 25 | 10 |
| 重點 | 120 | 40 | 24 |
| Boss | 240 | 50 | 48 |

（數字單位是 ticks；畫面上會換算成 `B` 顯示。）

**分級怎麼決定**：有名字的關鍵反派 → 獨立血條；無名雜兵 → 合併成一條「戰線狀態」，避免一場攻城戰生出幾十條血條。

---

## 六、傷害怎麼算（完全透明，可查）

每個玩家各自算一個比值：

```
r = 你的招式威力(Atk_BP) / 反派的防禦閾值(Villain_Guard)
```

| 你的 r | 結果 | 扣血 |
|---|---|---|
| r ≥ 2.0 | 碾壓 | 20 |
| 1.0 < r ≤ 2.0 | 壓制 | 10 |
| 0.9 ≤ r ≤ 1.0 | 僵持 | 2（**只有全員都沒破防才算，且一整回合只算一次**） |
| r < 0.9 | 無效 | 0 |

然後：

```
這回合總扣血 = min(所有人加總, 每回合上限, 剩餘血量)
```

**反派防禦閾值不需要任何人填**，由系統從反派的體質與結界純計算得出——不是 AI 隨意給的數。

攻守也不是靠「誰先講」決定的。

---

## 七、資料保存多久

兩條規則**同時生效**：

- **絕對上限**：從**建立日**起算 **180 天**，到期直接刪除。
- **滑動續期**：只要還有戲份，從**最後一次更新**起算延長 **30 天**。

續期永遠不會超過半年上限。也就是「最長可維持存放半年」。

**血條歸零不等於刪資料**：會標記成終局狀態（打敗／擊退／封印），帳本保留到 TTL 到期，方便日後劇情回收同一個反派。

---

## 八、管理員：怎麼讓反派有血條

原則上是**全自動**的——偵測到反派就會建立。

需要手動註冊時，用自然語言描述即可（系統會解析寫入），例如：

```
新增反派血條：魔王，重點級
```

系統會自己算防禦閾值（體質隱藏分數 × 結界修正），**不需要你填數值**。

要知道的事：

- 反派的血條長度、每回合上限、防禦閾值在**建立時就凍結**，同一場戰鬥內不會變。
- 反派在新篇章再登場 = **新的 battle_id**，血量由上次的擊退快照續接。
- 自動偵測建立的反派一律**不啟用動態難度校準**（那需要填篇章上場角色清單，是手動流程）。

## 九、目前狀態與「第一次試玩」檢查清單

⚠️ **請注意**：這套功能目前**通過了程式層驗收，但還沒有在真實 Discord 上跑過**。所有自動化測試都把 Phase A 的 AI 判定模擬掉了，所以**唯一還沒被驗證的環節是真實 AI 會不會正確吐出多人清單**。

第一次試玩請照這個順序確認：

1. 找**兩個玩家**，在同一討論串裡對**同一隻反派**各描述一次攻擊。
2. 執行 `/clash`。
3. 看系統的判斷（思維鏈／log）——**是否兩名玩家都進入了結算**。
4. 討論串是否出現**血條 + 一行理由**。
5. **再按一次確認**——血量**不應該**再扣第二次（防重複扣血）。
6. 沒有設定 `PYTHONIOENCODING` 也**不應該**報任何編碼錯誤。

**如果第 3 步只出現一個人**，那就是 AI 沒有吐出多人清單（提示詞要調），而不是血條壞了。

## 十、還不支援

- **多對多團戰**（多人對多個反派）——列為未來版本。
- **玩家自己的血條**——玩家受傷純屬敘事，系統不追蹤。血條只有反派有。
